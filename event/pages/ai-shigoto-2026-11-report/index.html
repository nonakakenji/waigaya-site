AIに、仕事を任せてみた。

2026年11月21日（土）13:00〜15:00、わいが舎のリビングで「AIエージェントに仕事を任せよう会」をひらきました。
チャットで「聞く」AIの先、仕事を任せるAIを、それぞれが自分のパソコンで動かした2時間です。

ABOUTどんな会だったか

話を聞く時間は合わせて30分ほど。あとはずっと、自分のパソコンで手を動かす会でした。

最後には、ひとりひとりが自分専用のAIエージェントを1人作って、名前をつけて、仕事を頼むところまで進みます。

教えたのは、わいが舎オーナーの健ちゃん。ふだんから、わいが舎の仕事をAIに任せて回しています。

LEARN 1チャットとエージェントのちがい

チャットは、聞くと答えの文章が返ってきます。それを読んで、写して、形にするのは自分です。

エージェントは、頼むと自分で調べて、ファイルを作って、「できました」と返してきます。そのあいだ、こちらは別のことができます。

チャット

答えが返ってくる。手を動かすのは自分。

エージェント

調べて、作って、報告してくる。手を動かすのはAI。

ちがいは、だれが手を動かすか。

ここで覚えて帰るのは、この1つだけ。会の最初に健ちゃんのエージェントに頼んだ「参加者のまとめ」も、頼んだら待たずに話を進め、あとで見るやり方にしました。

LEARN 2任せていい仕事、人が見る仕事

任せていい仕事

  • 下書き（メール・企画書）
  • ページや資料を、作って仕上げる
  • 録音から議事録をまとめる
  • 見はり（申し込み・欠席に気づいて知らせる）

人が最後に見る仕事

  • お金
  • 外に送るもの
  • 個人情報

メールも、AIが書くのは下書きまで。送るボタンを押すのは人です。健ちゃんも、読んでからボタンを1つ押しています。

LEARN 3自分専用のエージェントを作った

後半の40分は、ひとりひとりが自分のエージェントを作る時間。健ちゃんの見本を写して、自分だけの置き場を作り、Claude とつなぎました。

  1. GitHub のアカウントを作る無料のプランで。メールに届く数字を入れて、できあがり
  2. 自分の置き場「my-agent」を作る鍵つき（非公開）。中を見られるのは自分だけ
  3. Claude とつなぐつなぐのは my-agent だけ。ほかの置き場は選ばない
  4. 自分のことを入れて、名前をつけるAIが1問ずつ聞いてくるので、一言で答える。最後にエージェントに名前をつける
  5. 確かめる新しい会話で「あなたの名前は？」と聞いて、つけた名前で答えたら完成

答えたことは、エージェントの指示書（CLAUDE.md）にまとめて、自分の置き場にしまいます。だから家で開いても、同じエージェントが自分のことを覚えたまま動きます。

※ 実名・パスワード・カード番号は書かない、を最初に決めてから始めました。

LEARN 4エージェントは、育てていくもの

エージェントは作って終わりではありません。使うたびに、自分の仕事に合っていきます。

記録していくのは、この4つ。決めたこと／自分の好み／よく使う手順／失敗したこと。書きとめるのはエージェント。こちらは言うだけです。

何度もやる仕事は、手順ごと覚えさせておけます（スキル）。たとえば議事録なら「録音を読む→図を入れてまとめる→URLを知らせる」。毎回説明しなくてよくなります。

  • 使うたびに「これ覚えといて」と言う
  • ダメだったところは自分で直さず、「ここがちがう」と伝えて直させる
  • いっぺんに全部任せない。任せる仕事を1つずつ増やす

最後の25分は、さっそく自分のエージェントに「あなたに任せたいことを3つ以上、スライドにして」と頼んで、できたところまでを見せ合う時間にしました。

11月19日：アプリ版に変わりました

当日は、文字だけの画面（ターミナル）ではなく、Claude のデスクトップアプリの中の Claude Code を使います。アプリ版はアップデートがとても早く、これからはアプリで使っていくほうがよいと考えて、変更しました。黒い画面に1行を貼りつける作業がいらなくなるので、準備は簡単になります。

前の手順（ターミナル版）で入れ終わった方は、そのままで大丈夫です。当日はどちらでも使えます。

11月20日（金）までに、⑤ の「準備完了」まで 会は 11月21日（土）13:00〜15:00、シェアハウスわいが舎で開きます。
  1. 用意するものパソコン・ネット・Claudeの有料プラン
  2. Claudeに登録して、Proにするブラウザでの申し込み
  3. デスクトップアプリを入れるダウンロードして開くだけ
  4. ログインして、Claude Code を開く左上の「</>」を押す
  5. うまく動いたか確かめるこれが出たら準備完了

つまずいたときの連絡先は、いちばん下にあります。

1用意するもの

  • パソコン（Mac か Windows） Mac は macOS 13 以上、Windows は Windows 10（バージョン 1809）以上。メモリは 4GB 以上が目安です。
    スマホやタブレットではできません。当日もこのパソコンを持ってきてください。
  • インターネット 入れるときも、使うときも、ネットにつながっている必要があります。
  • Claude の有料プラン（Pro 以上） 無料のプランでは Claude Code は使えません。次の ② で申し込みます。
    すでに Pro・Max に入っている人は ② を飛ばして ③ へ。

Mac のバージョンは、画面の左上のりんごのマーク →「このMacについて」で見られます。

2Claudeに登録して、Proにする

  1. パソコンのブラウザ（Chrome・Safari・Edge など）で claude.ai を開きます。

  2. Google のアカウントか、メールアドレスで登録します。

    メールアドレスで登録したときは、届いたメールの中のリンクを押すと進めます。

  3. 料金のページ claude.com/pricing を開いて、「Pro」を選んで申し込みます。カードの情報を入れたら完了です。

Pro の料金（2026年10月29日に公式ページで確かめた金額）

月ごとに払う：1か月 20ドル
1年分をまとめて払う：200ドル（1か月あたり 17ドル）

表示は米ドルで、税は別です。料金は変わることがあるので、申し込む画面に出る金額で確かめてください。お支払いはご自身のカードになります。

3デスクトップアプリを入れる

  1. パソコンのブラウザで claude.com/download を開きます。

  2. Mac の人は Mac 用、Windows の人は Windows 用をダウンロードします。

  3. ダウンロードしたファイルを開いて、画面の案内にそって入れます。

    Mac は、出てきた画面で Claude のアイコンを「アプリケーション」フォルダに入れます。

4ログインして、Claude Code を開く

  1. 入れた Claude のアプリを開いて、② で作ったアカウント（Pro）でログインします。

  2. 画面の左上にある 「</>」のマーク（Claude Code）を押します。

    吹き出しのマークがふつうのチャット、「</>」が Claude Code です。

  3. 作業するフォルダをきかれたら、デスクトップなどに 「ai-renshu」 という名前の空のフォルダを作って、それを選びます。

    空のフォルダなので、中のファイルを心配しなくて大丈夫です。当日もこのフォルダを使えます。

画面の名前や場所は、アップデートで少し変わることがあります。

5うまく動いたか確かめる

文字を打ちこむ欄に、こう打って送ってみてください。

こんにちは。準備ができたか確かめています

日本語で返事が返ってきたら、準備完了です！

これで当日はすぐに始められます。お疲れさまでした♪

?つまずいたとき

よくあるつまずきです。出た文字が近いものを開いてみてください。

「</>」のマーク（Claude Code）が見つからない

アプリが古いかもしれません。アプリを最新にしてから開き直してください（Mac は画面の上のメニューの「Claude」→ アップデートの確認）。

それでも出ないときは、ログインしているのが有料プラン（Pro 以上）のアカウントか確かめてください。無料のプランでは Claude Code は使えません。

ログインできない・ブラウザが開いたまま進まない

ブラウザで開いた画面で、② で作ったアカウントにログインして「許可」を押してから、アプリに戻ってください。

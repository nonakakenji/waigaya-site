1用意するもの

  • パソコン（Mac か Windows） Mac は macOS 13 以上、Windows は Windows 10（バージョン 1809）以上。メモリは 4GB 以上が目安です。
    スマホやタブレットではできません。当日もこのパソコンを持ってきてください。
  • インターネット 入れるときも、使うときも、ネットにつながっている必要があります。
  • Claude の有料プラン（Pro 以上） 無料のプランでは Claude Code は使えません。次の ② で申し込みます。
    すでに Pro・Max に入っている人は ② を飛ばして ③ へ。

Mac のバージョンは、画面の左上のりんごのマーク →「このMacについて」で見られます。

2Claudeに登録して、Proにする

  1. パソコンのブラウザ（Chrome・Safari・Edge など）で claude.ai を開きます。

  2. Google のアカウントか、メールアドレスで登録します。

    メールアドレスで登録したときは、届いたメールの中のリンクを押すと進めます。

  3. 料金のページ claude.com/pricing を開いて、「Pro」を選んで申し込みます。カードの情報を入れたら完了です。

Pro の料金（2026年10月29日に公式ページで確かめた金額）

月ごとに払う：1か月 20ドル
1年分をまとめて払う：200ドル（1か月あたり 17ドル）

表示は米ドルで、税は別です。料金は変わることがあるので、申し込む画面に出る金額で確かめてください。お支払いはご自身のカードになります。

3Claude Code を入れる

Claude Code は、文字で指示を打ちこむ画面（Mac では「ターミナル」、Windows では「PowerShell」）から入れます。
見なれない画面ですが、下の1行をコピーして貼りつけるだけです！

Mac の人

  1. ターミナルを開く

    キーボードの command と スペース を同時に押して、出てきた検索窓に「ターミナル」と打って return。

    白か黒の、文字だけのウィンドウが開きます。これがターミナルです。

  2. この1行をコピーして、ターミナルに貼りつける

    curl -fsSL https://claude.ai/install.sh | bash

    貼りつけは command ＋ V。貼れたら return を押します。

  3. 終わるまで待つ

    途中は何も表示されないことがありますが、そのまま待ってください。最後にこう出たら入りました！

    Claude Code successfully installed!

  4. ターミナルをいったん閉じて、もう一度開く

    開き直さないと、次の ④ で「見つからない」と出ることがあります。

Windows の人

  1. PowerShell を開く

    キーボードの Windowsキー と X を同時に押して、出てきた一覧から「Windows PowerShell」か「ターミナル」を選びます。

    名前に「(x86)」とついているものは選ばないでください。

  2. PowerShell になっているか確かめる

    行の先頭が PS C:\Users\（あなたの名前）> のように PS から始まっていれば OK です。

  3. この1行をコピーして、貼りつける

    irm https://claude.ai/install.ps1 | iex

    貼りつけは Ctrl ＋ V（または右クリック）。貼れたら Enter を押します。管理者として開く必要はありません。

  4. 終わるまで待つ

    途中は何も表示されないことがありますが、そのまま待ってください。最後にこう出たら入りました！

    Claude Code successfully installed!

  5. PowerShell をいったん閉じて、もう一度開く

    開き直さないと、次の ④ で「見つからない」と出ることがあります。

4はじめて起動して、ログインする

  1. 練習用のフォルダを作って、そこに移る

    開き直したターミナル（Windows は PowerShell）に、この1行を貼りつけて return（Enter）。Mac も Windows も同じ1行です。

    mkdir ai-renshu; cd ai-renshu

    「ai-renshu」という名前の空のフォルダができて、その中に入ります。当日もこのフォルダを使えます。

  2. Claude Code を起動する

    claude と打って return（Enter）。

    claude

  3. 画面の案内にそって進む

    はじめてのときは、英語の質問がいくつか出ます。矢印キーで選んで return（Enter）で進めます。
    ログインの方法をきかれたら、Claude の有料プラン（Pro など）のアカウントを選んでください。

    ターミナルの中はマウスで押せません。矢印キーと return（Enter）で動かします。

  4. ブラウザでログインする

    自動でブラウザが開くので、② で作ったアカウントでログインして、許可します。ターミナルにこう出たら OK です。return（Enter）で進みます。

    Login successful

    ブラウザが開かないときは、ターミナルで c を押すとログイン用のアドレスがコピーされるので、ブラウザに貼りつけて開いてください。ブラウザにコードが出たときは、ターミナルの Paste code here if prompted のところに貼りつけます。

  5. このフォルダを使ってよいかきかれたら

    はい（Yes）を選んで進めてください。さっき作った空の練習用フォルダなので、心配いりません。

5うまく動いたか確かめる

文字を打ちこむ欄が出て、その上に Claude Code の番号（バージョン）などが表示されていたら起動できています。
ためしに、こう打って return（Enter）を押してみてください。

終わるとき

exit と打って return（Enter）。そのあとターミナルを閉じて大丈夫です。

入っているかだけ確かめたいとき

ターミナルで次の1行を打つと、番号が表示されます。

claude --version

たとえば 2.1.211 (Claude Code) のように、数字のあとに (Claude Code) と出れば入っています。数字は人によって違います。

?つまずいたとき

よくあるつまずきです。出た文字が近いものを開いてみてください。

Mac：command not found: claude と出る

まずターミナルを閉じて、開き直してからもう一度 claude を打ってみてください。
それでも同じなら、この2行を1行ずつ貼りつけて return。

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

そのあと、ターミナルを開き直して claude を打ちます。

Windows：'irm' is not recognized と出る

開いているのが PowerShell ではなく「コマンドプロンプト」です。行の先頭に PS がついていません。
ウィンドウを閉じて、③ の手順で PowerShell を開き直してください。

そのままのウィンドウで入れたいときは、代わりにこの1行を使います。

curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
Windows：'claude' is not recognized と出る

まず PowerShell を閉じて、開き直してからもう一度 claude を打ってみてください。
それでも同じなら、PowerShell でこの2行を1行ずつ貼りつけて Enter。

$currentPath = [Environment]::GetEnvironmentVariable('PATH', 'User')
[Environment]::SetEnvironmentVariable('PATH', "$currentPath;$env:USERPROFILE\.local\bin", 'User')

そのあと PowerShell を閉じて開き直し、claude を打ちます。

Mac：dyld や built for Mac OS X 13.0 と出る

Mac のバージョンが古いかもしれません。りんごのマーク →「このMacについて」で 13 より前なら、「ソフトウェアアップデート」で新しくしてからもう一度やってみてください。
